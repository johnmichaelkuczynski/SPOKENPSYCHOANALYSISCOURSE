---
name: Applied assessment
description: Fresh-case adjudication rather than memorization is the course's assessment requirement.
---

Each test or homework question should describe a fresh situation and have the user adjudicate it. Use the lecture's concepts, but do not ask the student to recall facts or explanations from a case already discussed. The user explicitly said this is not a memorization course.

**Why:** The user rejected questions answerable by memorizing what happened in a lecture case, then clarified: "EACH QUESTION SHOULD DESCRIBE A FRESH SITUATION AND HAVE THE USER ADJUDICATE IT".

**How to apply:** Present new situations requiring a judgment and reasons grounded in case details. Grade application and justification, accepting defensible alternative judgments rather than matching a single model answer. Preserve this requirement for lecture assessments, final exams, follow-up probes, and retakes.
