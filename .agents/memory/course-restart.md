---
name: Restarting the course
description: Why Restart class begins a fresh course run instead of erasing previous work.
---
Restart class starts a fresh course run, with initial lecture position and fresh assessments, rather than permanently deleting the student's previous coursework.

**Why:** The user asked to restart the class, not erase records. A fresh run allows an immediate action without a confirmation dialog or accidental loss of earlier work, and avoids changing other browsers' progress in the shared development default.

**How to apply:** Keep the restart scoped to the initiating browser and preserve previous records. Do not silently replace this with destructive deletion. Voice and speed preferences should not be reset along with course progress.
